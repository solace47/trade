# 控股股东质押风险下降：原件与事前检验

2026-09-25 固定，**本事件收益尚未读取**。假设：直接控股股东已办理股份解除质押，且其累计质押股数占直接持股的比例跨越一个官方高质押风险披露层级并至少下降 5 个百分点，可能降低被动处置和控制权不稳的预期；公告后的首个交易日 14:50 买入，T+5 净收益相对同日相似股票可能为正。这只是待检验的短期关联假设。[上交所的质押披露说明](https://www.sse.com.cn/services/investors/questions/sell/c/c_20220426_5701501.shtml)以 50% 和 80% 分层；[原始研究](https://doi.org/10.1016/j.irfa.2021.101839)报告质押期间长期崩盘风险增加，但该结论不能直接推出解除质押后的五日收益。

## 原件与门槛

- 从巨潮资讯按“解除质押”完整分页检索 2024/2025 年，核对每页和全年官方总数。标题保守限定为直接“控股股东”且仅出现一次“质押”；排除标题提及一致行动人、可转债/可交换债或拟办理的公告。标题只用于减少原件核验量，不决定入选。`python -m scripts.collect_pledge_release_index --year 2024`、`--year 2025` 可复算索引。
- 逐份核实 PDF 首页股票身份、直接控股股东身份、**已经登记解除**的股数、解除前后其直接累计质押股数与直接持股股数。只纳入解除前比例至少 50%、解除后跨到 50% 以下，或解除前至少 80%、解除后跨到 80% 以下，且比例下降至少 **5 个百分点**的单次净解除；同份公告实际新增或重新质押、尚待办理、可交换债担保解除、强制执行、主体或比例无法核实者剔除。不能把关联方股数借给控股股东；同股同日重复原件剔除。原件核验和人数覆盖不足时不读收益。
- 披露后首个交易日才产生信号。使用既有全市场 14:50 可交易股票池，每日最多五只、同股十交易日冷却；同日同板块、相近规模与事前动量且无本事件公告的股票无放回配对，同行业另查。两年各须至少 **30** 个严格配对事件、覆盖至少 **六个月**，否则停在输入可行性阶段。

## 冻结的收益检验

门槛通过后，预设主终点为每笔 2 万元、14:52–14:55 原始分钟买入、T+5 退出的现金感知净收益，事件减同日对照按日期等权并对整月重抽样；预期为正。另查 T+1、上下半年、同行业、10 万元、每侧额外 10 基点成本、买卖覆盖及跨年退出。2023 年及以前仅作指标预热。2025 年已被多次查看，不能称盲测；2026 年只考虑本方案冻结后的披露作前瞻验证。即使历史结果为正，仍需成交可行、跨期稳定与独立留出才能发布公式。
