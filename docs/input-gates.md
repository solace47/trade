新评价统一09:31—09:59，要求连续三根正成交分钟按统一成本估值后为正；另报至少1%空间、09:59参考和至少3%不利幅度。完整观察可以含零量分钟，所以已知机会不保证09:59有活跃参考价。参考缺失保留，不补零、不当负事件、不用其未来可用性筛股。

先逐日汇总再对日期等权，另列逐股汇总、未知上下界、未买入、整日未知及独有日。旧09:31—10:00记录保留原义，少观察一分钟导致风险减少不是策略改善。当前不研究实际卖出规则、持有两三天或多日兑现。

成熟未知可用于明确的可核准成功证据目标，但原实际事件区间始终为[0,1]；确定未买入为[0,0]。训练下界指示量为零不意味着未知收益为零，拟合分数不是机会概率下界。所有观察日期必须严格早于训练终点；空值、延迟或错序不能自动赋负事件。

## 固定顺序与复用

1. 固定问题、输入来源、语义与质量要求，先查已有协议和缓存，防止重做或仅改名。
2. 全量生产结果由独立实现核准，原生数学另核对；训练标签的观察终点必须严格早于测试开始。
3. 固定模型参数、权重、训练门槛及所有完整名单，提交联合收据后再看新分组经济结果。
4. 汇总前比较完整选择表、元数据、适用标签及来源指纹；全部相同才复用统计，不能只比较入选数量。
5. 年度报告已含两半年时不再重复聚合；同日和共享未知比较也先精确查重。所有失败和未知保留，不因结果不好覆盖冻结产物。

## 客户端落地

通达信实际编译通过的内容仅包括原48项、大小盘交集数值核心、横向计数／INSUM语法及部分已完成日线辅助调用。完整条件选股、历史股本代理与FINANCE(7)、历史指数代表价与INDEXC、客户端成员集合、临停、实时数据时效及历史加载深度仍需分别核准。数学重放通过不等于这些数据和行为已一致。

2026-10-01客户端补查仅进入新建指标信息页，未完成50项源码编译；未保存草稿已关闭，不增加编译通过声明。应用打开时初始界面显示2026-09-30行情概览，属于已暴露界面信息，不能再称该界面完全未见。它没有进入模型、选股名单或经济评价；机器收据的未读2026标志只说明研究程序未新增读取2026行情／标签，不涵盖这次界面展示。

CLOSE受客户端复权状态影响；本库当前价格输入为已注明的未复权定义，不能混用复权价与成交额／成交量均价。历史日线辅助指标必须先REF到已完成日线再由分钟侧引用；客户端补线与零量占位设置须一致。

[内部排除配置](../config/formula_exclusions.json)只保存基础要求，不能当作研究成果。`NAMEINCLUDE('ST')`、`CODELIKE`、`INBLOCK`和动态交易状态的完整筛选还须实机核验；当日已有成交后临停，不能仅凭累计成交量判定此刻可交易。

## 已结束支线的可见性要求
