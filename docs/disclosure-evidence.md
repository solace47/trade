# 公告、财报与基金支线的保留口径

这些 2024–2025 年探索均未形成满足跨期净收益、同日优势与成交门槛的尾盘公式；2025 年不是盲测，2026 年未用于这些规则。各项数值结论汇于[策略结果](strategy-results.md)，准确的事前规则留在 Git 历史，程序和本地忽略的 `data/` 保存复算入口。当前研究转回 14:49 前分钟量价、流动性和实际成交。

- **公告可见时间。** 巨潮索引只有可靠的发布日期；抽查的公告时间字段不能还原当日具体发布时刻，所以相关信号保守延到披露后下一交易日。回购、增减持标题只能预筛，股票身份、实际成交额、用途和计划起止均须核对原件；公告中的减持计划不等于当天实际卖出。月度回购进展批量 PDF 支线已停止。
- **年报现金代理。** 从 2023/2024 年报摘要索引 10,029 份中可靠提取 9,939 份利润与经营现金流，90 份拒解析，不对失败原件回填。现金流／利润只是简化代理，不能当正式应计项或知情交易。[张小泉 2023 原始摘要](https://static.cninfo.com.cn/finalpage/2024-04-29/1219869174.PDF)中相邻页的 2022 年调整项曾造成错配；提取程序要求利润位于现金流之前或同页，两者页距最多一页。
- **回购与增减持。** 回购方案原件核验 2024/2025 年 1,227/425 份；首次实际回购 1,427/567 份。纯注销用途从逐份复核后仅 59/36 份。增持计划核验 333/191 份，减持计划 433/725 份；多数减持计划约 15 个交易日后才可开始。首次增持、过半零执行及减持完成的严格同日样本较少，具体限制见[策略结果](strategy-results.md)中的相应条目。
- **公募可见度。** 已公布的基金前十重仓只是全部机构持股的不完整子集；季末持仓只在披露后可见。以披露股数除以季末流通股得到的是持股下界代理，不等于实时持股、机构关注度或真实订单流。基金上榜与高低持股分组均未通过跨年优势检验。

保留的主要复算程序为 `scripts/extract_original_annual_cash.py`、`scripts/validate_buyback_cancellation_review.py`、`src/trade_research/first_buyback_inputs.py`、`src/trade_research/insider_sell_completion_inputs.py` 与基金原件处理模块；逐份人工复核表保存在 `research/`，原件与机器审计文件留在本地忽略目录。若未来重新使用公告或基金数据，须先从 Git 历史核对当时冻结规则，再重新确认可见时点、来源覆盖和交易终点。
