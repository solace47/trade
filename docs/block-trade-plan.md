# 大宗交易折价：原始输入与事前检验

2026-09-25 固定本假设及口径，**尚未读取按本信号分组的收益**。2025 年其他策略的结果已经多次查看，不能称为盲测；2026 年留给规则冻结后的独立验证。研究对象仅为沪深 A 股，不包括页面中的基金、B 股及其他证券。

## 经济理由与可观测时间

[Bian、Wang、Zhang（2012）论文摘要](https://ideas.repec.org/a/eee/chieco/v23y2012i1p181-189.html)记录早期中国市场多数大宗交易不高于竞价收盘价，过半不高于当日最低价，并报告总体负面市场反应，解释为可能的卖方发起交易。它不能证明 2024 年以后的效应，更不能证明次日 14:50 仍有可交易余量。待证假设是：**交易日 d 的协议大宗交易若以足够金额、明显低于当日普通竞价最低价成交，d 的下一交易日 14:50 买入后的 T+5 净收益低于同日同行业、同板块的非大宗交易股票**。这是潜在的买入排除条件；不得把大宗成交价当作普通投资者能够买到的价格。

[上交所逐笔页面](https://www.sse.com.cn/disclosure/diclosure/block/deal/dzjyxx/)公开交易日、价格、金额、成交量与买卖营业部；[深交所权益类大宗交易页面](https://www.szse.cn/disclosure/deal/block/equity/index.html)按日期提供协议交易逐笔价格、金额及营业部。两所均已用 2024-09-24 的页面原件核查历史可回查性。大宗交易资料至少待 d 收盘后才可完整取得，故只在 **d 的下一交易日**建 14:50 信号；同日 14:50 绝不使用 d 的大宗记录。只用交易所协议交易逐笔数据；深交所“盘后定价”另列，不混入折价样本。

## 冻结输入与主比较

- 将两所 2024–2025 年全部交易日的协议交易逐笔归档到被 Git 忽略的 `data/research/block_trade/`。对交易日、六位代码、价格、数量、金额、总行数、分页完整性和公开页面的抽查日做校验；抓取或字段失败须显式报告，不把缺失日当无事件。
- 用 BaoStock **不复权**日线的 d 日普通竞价最低价计算折价。逐笔价格须严格低于 `0.99 × d 日最低价`，且同股同日满足这一条件的协议交易金额合计至少 **1,000 万元**；日线缺失或价格异常则拒绝该股日。重复逐笔成交保留并计入真实披露总额，不按相同价格去重。公告日期只在 2024 年及以后；更早数据仅可作指标预热。
- 下一交易日 14:50 使用当时可见的完整市场股票池与流动性、停牌、ST、上市年龄等已有成交门槛。每天最多取折价深度最大的 **5** 只，金额仅作同深度时的排序；无信号日单列，不虚构交易。
- 主比较为 2 万元/笔、14:52–14:55 原始分钟买入、T+5 退出的现金感知净收益。每只事件股在同一信号日，找没有 d 日任何协议大宗交易、具有相同事前行业分类与板块的可交易股票；以 20 日成交额、此前 20 日收益和当日 14:50 前收益的标准化距离选最近一只，平局按代码固定。配不上不得改用未来信息或悄悄换行业，单列失配率。先逐信号日平均事件减对照，再跨日等权；2024、2025 分开报告，整月重抽样 95% 区间。
- 辅助查看 T+1、10 万元/笔、每侧额外 10 基点、上下半年、剔除最密集月份及同日全部合格信号；同时报告买卖覆盖、失配、原始逐笔日期覆盖、行业与板块分布。若主比较跨年不稳定、区间未支持负差或容量不足，就不发布排除公式，更不把结果反转成买入公式。

2024–2025 年仅用于探索性筛选和收益计算；2026 年数据在本假设检验前不读取收益。原始文件与机器结果留在本地忽略目录，本文只保留门槛与最终有效结论。
