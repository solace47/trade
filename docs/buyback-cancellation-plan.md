# 回购方案明确注销用途：输入核验与预设检验

2026-09-25 固定本子组规则，**尚未读取按回购用途分组的收益**。此前已查看总体回购方案、首次实际回购及资金下限的 2024/2025 年结果，因此此处仍是探索，2025 年不能称盲测。国务院[2024 年资本市场意见](https://www.csrc.gov.cn/csrc/c100028/c7473562/content.shtml)要求引导上市公司回购股份后依法注销；这说明注销与员工持股等用途在制度上有区别，**并不证明**公告后五日存在可交易超额收益。待证假设是：明确全部用于注销并减少注册资本的回购方案，在公告后的下一交易日 14:50 买入，T+5 净收益高于同日相似的非公告股；其优势可能高于明确用于员工持股或股权激励的方案。

输入沿用已冻结的 2024/2025 年回购方案原件及 **419/250** 对同日非公告对照，不重新按收益挑股票。逐份复核这 **669** 份原始公告的用途：只有当文件明确把本次计划的**全部**回购股份用于注销、减少注册资本且没有员工持股、股权激励、可转债转换或“维护价值后择机处置”等并列用途时，才记为纯注销；计划未实施时或三年未转让时的条件性注销不算。用途在原件前三页无法核实时记未知，不用推测填补。控制组继续排除同日公告股；计划更改和同股多份公告按原冻结名单的日期处理。人工审阅台账须在收益读取前完成，两年各至少 **30** 对、覆盖至少 **六个月**，否则只报告输入可行性。

若输入门槛通过，主终点为每笔 2 万元、14:52–14:55 原始分钟买入、T+5 退出，先算事件减其同日对照的现金感知净收益，再按信号日等权；整月重抽样区间须支持跨年稳定的正差值。另查明确员工用途的独立配对组、上下半年、T+1、同行业可比性、10 万元与每侧额外 10 基点成本，并报告买卖失败；同日两用途有足够重叠时才比较两组的增量差。2023 年及更早仅供行情预热，2026 年留给事前冻结后的独立验证；未通过所有门槛不发布公式。

[既有用途预筛](buyback-plan.md)仅将前三页局部文本机械分类，纯注销暂有约 **53/36** 份线索，并有 **47/19** 份用途未知；混合用途、勾选框和文本提取错位都可能造成误判。这些数字不是经原件核准的事件数，不能据此读取收益。
