# 旧尾盘岭模型：保留的教训

这些模型在 2024–2025 年反复训练和诊断，2025 年不再是盲测，2026 年没有用于调参或验证。策略结果以[总表](strategy-results.md)为准；原冻结细节与完整输出可由 Git 历史、`src/trade_research/absolute_ridge*.py` 及本地忽略的 `data/research/absolute_ridge*/` 查回。以下只保留未来研究需要避免的失败机制。

| 已结束的检验 | 有效结论 |
| --- | --- |
| 全板块绝对净收益重训 | 18 项 14:50 前特征、10 万元 T+5 含费目标、预测值 >0 才买、每日最多五只；2024 上半年训练、2024 下半年和 2025 年测试。模型每天仍选满五只，同日严格配对仅 **68.9%**，低于预设 70%；按冻结门槛没有读取新名单测试收益。 |
| 只在主板重训 | 配对覆盖提高至 **83.2%**，但 2024 下半年、2025 上下半年的自身净收益为 **−0.85%/−0.31%/+0.28%**，同日差 **−1.27/−0.50/+0.19** 个百分点；10 万元买入覆盖 **85.2%/85.5%/91.6%**。每侧 15 基点、2 万元与次晨退出未修复跨期失效；6,376 条 10 万元尾盘复价与存档一致。 |
| 全主板分数校准 | 508,727 个股票日的最低分组 Q1 比 Q5 弱，但 Q5 减中间组 Q3 的三段差仅 **−0.03/+0.10/−0.01** 个百分点，三段月块区间都跨零。低分风险分层不等于最高分可交易优势。 |
| 极端高分诊断 | 每日分数前 **0.5%** 的 T+1 净收益减 80%–95% 组为 **−0.58/−0.28/−0.10** 个百分点，10 万元买入覆盖仅 **84%/86%/92%**；T+5 同日差亦负但跨期区间不全低于零。不能因此事后改买 80%–95% 组，该组未按五只容量和重叠持仓验证。 |
| 压低尾盘绝对波动系数 | 在主板模型中把 `abs_return_last30` 系数限制为非正，名单尾盘绝对涨跌中位数降至 0.24%，但 10 万元买入覆盖降至 **75%/74%/82%**；T+5 同日差 **−0.14/−0.28/−0.39** 个百分点。新名单更多接近涨停或受四分钟容量限制，逐笔复价未改变结论。 |

这些测试显示，缩小板块、重标定分数和只约束一个风险特征均没有同时产生稳定正净收益、同日优势及可靠成交。不要在同一两年数据上继续调高分阈值；若以后重新建模，应先取得真正未查看的时期或新数据，并事前固定执行规则。
